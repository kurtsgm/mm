# A1 音訊框架（production-plan M-A/A1）design

> 2026-07-05 · 目標：BGM 依地圖切換＋crossfade、戰鬥曲進出、SFX 事件掛點、音量設定持久化。**框架先行**：正式曲目/音效由 M-B 音訊組（CC0 選曲）落地，本包附最小程序化佔位音（可聽見換曲/命中）供人工 gate 驗證。

## 0. 現況（Explore 已證實）

零音訊碼。autoload 3 個（MapManager/GameState/SaveSystem，皆不給 class_name）。戰鬥進出對稱點＝`main.gd` `_set_overworld_visible(false)`(253)↔`_on_combat_finished`(310)。地圖就緒 4 點＝啟動(128)/recenter(197)/link(231)/讀檔(575)。無 ConfigFile；存檔範圍明確不含偏好設定。

## 1. 架構

- **`autoload/audio_manager.gd`**（autoload 名 `AudioManager`，不給 class_name，追加在 SaveSystem 後）：
  - **Music**：兩台 `AudioStreamPlayer`（bus=Music）做 crossfade（1.0s tween）；`play_map_bgm(track_id)` **同曲 no-op**（無縫 recenter 不重啟）；`push_combat_bgm()`／`pop_combat_bgm()`（記住地圖曲、戰後恢復；DEFEAT 不恢復、直接 `stop_music()`）；loop 用 `finished` 信號重播（不依賴 import loop 參數）。
  - **SFX**：`play_sfx(id)`，8 台 `AudioStreamPlayer` 輪播池（bus=SFX）。
  - **未知 id／缺檔＝靜音略過**（資料驅動的內容缺席處理，非相容層）；一律不噴 error。
  - **音量**：`set_volume(bus_name, v: 0..1)`／`volume(bus_name)`，Music/SFX/Master 三檔；`user://settings.cfg`（ConfigFile）持久化，`_ready` 載入。設定檔路徑放 `var _settings_path`（測試可注入 temp 路徑）。**音量 UI 本包不做**（deferred：併入後續 QoL/選單包），先有 API＋持久化。
  - Bus：`_ready` 時若無 Music/SFX bus 則以程式建立並掛到 Master。
- **`engine/audio/audio_catalog.gd`**（`class_name AudioCatalog`，static，比照 TravelCatalog）：讀 `content/audio/tracks.json`（`{id → {path, stream? }}`）與 `content/audio/sfx.json`；`track_entry(id)`／`sfx_entry(id)` 查詢（避開 `get` 命名）。
- **`MapData.bgm: String`**＋importer 頂層 `"bgm"` 欄位（照抄 continent 模式，map_data.gd:25／map_importer.gd:37）。

## 2. 內容

- 10 張既有地圖標 `bgm`：野外四張＋晨橡近郊未來共用 `oak_wild`；`town_oak`＝`oak_town`；5 室內＝`interior`；（新地圖照 blockout 配曲，M-B 起）。
- `content/audio/tracks.json` 首發 4 條：`oak_wild`、`oak_town`、`interior`、`combat`（戰鬥曲 id 固定 `combat`，boss 曲後續加）。
- `content/audio/sfx.json` 首發 8 條：`hit`、`victory`、`defeat`、`chest`、`menu_open`、`menu_close`、`dialogue`、`levelup`（`quest` toast 共用 `dialogue` 或獨立，實作時定）。
- **佔位音**：程序化生成（Python 寫 PCM `.wav` 進 `content/audio/placeholder/`）：4 首短 loop 音床（不同音高，可分辨換曲）＋8 個短音效（click/beep 變體），首次匯入後連 `.import` 一起 commit。正式 CC0 資產 M-B 換檔即可（tracks.json 換 path、邏輯不動）。

## 3. 掛點（main.gd／presentation）

| 事件 | 位置（現行行號） | 呼叫 |
|---|---|---|
| 地圖 BGM | 啟動 128／recenter 197／link 231／讀檔 575 | `AudioManager.play_map_bgm(MapManager.current_map.bgm)` |
| 戰鬥進 | 253（`_set_overworld_visible(false)` 後） | `push_combat_bgm()` |
| 戰鬥出 | 310；DEFEAT 分支 331 | `pop_combat_bgm()`；DEFEAT→`stop_music()` |
| 命中閃白 | combat_layer.gd 306-307 | `play_sfx("hit")` |
| 勝利／覆滅 | main.gd 320／331 | `victory`／`defeat` |
| 開箱 | main.gd 351-354 | `chest` |
| 選單開/關 | main.gd `_toggle_menu` 523/529 | `menu_close`/`menu_open` |
| 對話推進 | main.gd 414 | `dialogue` |
| 升級 | main.gd 471 | `levelup` |
| 任務 toast | main.gd 116 旁加 connect | `dialogue`（或 `quest`） |

## 4. 測試策略

headless 用 dummy audio driver：**只驗狀態邏輯、不驗發聲**。AudioManager 以 `preload().new()`＋`add_child_autofree()` 測（test_map_manager 模式）：current_track_id 選曲/同曲 no-op、combat push/pop 恢復、DEFEAT stop、音量 set/get＋ConfigFile round-trip（temp 路徑注入）、catalog 查詢、importer bgm 欄位、未知 id 靜音不炸。

## 5. 驗收（A1 DoD）

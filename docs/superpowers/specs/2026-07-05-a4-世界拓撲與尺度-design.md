# A4 世界拓撲與尺度拍板（production-plan M-A/A4）design

> 拍板日：2026-07-05 · 決策者：製作總監 · 三決策：①LOCAL_MAP_SIZE 10→**16**；②跨大陸旅行＝**旅行點＋目的地選單**；③**世界地圖總覽畫面：做**（靜態插畫＋位置標記）。

## 0. 背景與既有事實

- 現行世界模型：local map JSON（`neighbors` 四向）→ `WorldStitch` BFS 無縫拼接（大陸內）；`portal` 跳轉（進城/室內/地城）。**引擎已天然支援多大陸**：一塊大陸＝一個 neighbor 相連叢集，大陸間本來就不相連。
- `MapData.LOCAL_SIZE = 10`，內容層測試強制所有 `content/maps/*.json` 為 10×10；現有 10 張地圖。
- 缺口：大陸間移動機制、全局定向感、大世界命名慣例。

## 1. 決策一：LOCAL_MAP_SIZE 10 → 16（含既有地圖遷移）

- `MapData.LOCAL_SIZE = 16`；內容層尺寸測試隨之改 16。importer 保持通用不限尺寸（沿用 uniform-size spec 的分層決策）。
- **遷移策略＝置中 padding**：既有 10×10 內容整體平移 **(+3, +3)**，四周各補 3 圈：
  - 野外（有 neighbors 的圖）：補 `.`（可走地形），必要時依主題補景（遷移時不做景觀精修，M-B 再美化）。
  - 室內/城鎮（portal-only）：補 `#`（牆），維持室內空間感；**全部地圖仍統一 16×16**（不放寬規則，測試單純）。
  - 所有 entities/entries/`@` 座標 +3；quest/dialogue 若引用格座標一併修（`check-quest` 驗證）。
- 波及測試：凡寫死尺寸/實座標者更新（uniform-size spec 已列候選清單）。
- **效能驗證 gate**：拼接渲染窗 half=max(w,h) 隨尺寸變大（可視 tile 數 ~2.5×），遷移後跑 boot＋四野漫遊煙霧測試確認無退化。

## 2. 決策二：跨大陸旅行＝旅行點＋目的地選單

- **資料**：新增 `content/world/travel_network.json`：節點 `{ id, name, map, entry, continent, unlock }`。`unlock` 為旗標名；起點大陸節點預設解鎖。
- **地圖掛點**：map JSON 新 entity `{ "type": "travel", "pos": [x,y], "node": "<node_id>" }`（港口/車隊格）。踩上觸發旅行選單。
- **解鎖**：`GameState.travel_unlocked: Set[String]`；由 dialogue/quest event effect（新 effect `unlock_travel`）寫入；入存檔（schema 直接改，pre-release 免相容）。
- **UI**：旅行選單復用既有服務選單模式（列出「已解鎖且非目前所在」節點）；確認後黑幕淡出→載入目的地圖 entry→淡入＋toast「抵達〈大陸·節點名〉」。旅行敘事卡待 A2 演出框架接手升級，本包先做極簡淡入淡出。
- **不做**：自由海圖航行（已否決）；旅費/隨機海上遭遇（後續內容期可加，不進框架）。

## 3. 決策三：世界地圖總覽畫面

- 按鍵（暫定 `M`）／選單開啟全螢幕覆蓋：**靜態世界地圖插畫**＋六大陸名稱＋**目前所在大陸高亮**＋已解鎖旅行節點標記。純 presentation、不可互動移動（旅行仍走旅行點）。
- 資料：`content/world/continents.json`：`{ id, name, map_rect(比例座標) }`；map JSON 新增欄位 `"continent": "<id>"`（既有 10 張全標 `oakmarch`）。
- 美術：首版用 gen_parchment 底＋程式繪製大陸色塊與標籤（比例式版面）；正式插畫列入美術組 M-C 前排程，屆時換圖不改邏輯。

## 4. 命名與組織慣例（新內容一律遵守）

- 新地圖 id 前綴＝大陸碼：`oak_`（橡境）、`fro_`（霜垠）、`ver_`（赤沙）、`dee_`（翠淵）、`imp_`（帝心）、`isl_`（碎島海）。**既有 10 張不改名**（減少 churn），僅補 `continent` 欄位。
- 地城樓層：`<地城名>_f1/f2/…`，樓層間用 portal；地城樓層自成叢集（可用 neighbors 拼超過 16×16 的大層）。

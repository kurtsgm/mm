# A2 演出框架（Cutscene / 過場序列）設計

> 建立：2026-07-06 · 里程碑：**M-A 前置補完 · A2** · 擁有者：製作總監
> 依 `docs/production-plan.md` §5 M-A：A2＝「過場序列（黑幕/章節標題卡/事件 CG 圖卡/強制對話串/鏡頭震動）；開場與章末過渡可資料驅動」。
> 前置：A1 音訊框架（`AudioManager`）✅、對話/事件 runtime（`DialogueRunner`/`DialogueOverlay`/`SceneImageCatalog`）✅。

## 0. 背景與立足點

演出的「原料」大多已在庫，A2 不是造新輪子，而是把它們串成**資料驅動的演出序列（timeline of steps）**：

| 原料 | 現況 | A2 如何用 |
|---|---|---|
| 黑幕 | `main.gd` `_fade_rect`/`_fade()`（0.2s，綁地圖轉場） | A2 自擁一套 fade 表面（與地圖轉場分離） |
| 事件 CG | `SceneImageCatalog`（全版圖，缺圖→純色 placeholder） | `cg` step 直接重用 |
| 強制對話串 | `DialogueRunner`＋`DialogueOverlay`（無選項節點＝強制推進） | `dialogue` step 用 player **自擁的** overlay 實例（見 §3.2 隱患） |
| 音訊 | `AudioManager`（`play_sfx`/`play_map_bgm`/`stop_music`） | `audio` step 直接對應 |
| 鏡頭 | `main.gd` `_camera: Camera3D`（過場期玩家 disabled、不會覆寫） | `shake` step 位移它 |
| 世界狀態改動 | `DialogueEffects`（set_flag/give/accept_quest…） | `effects` step 重用 |
| 觸發判定 | `SceneTrigger`（once/require）＋ `GameState.is/mark_scene_triggered` | scene schema 擴充後沿用 |

**核心取向（已評估三案）**：採「純資料 `CutsceneData` + presentation 非同步 `CutscenePlayer`」。
否決：(B) 純 step 狀態機——線性 step list 的邏輯只是 index++，真正複雜度全在時序/非同步，狀態機擁有不了，徒增儀式；(C) Godot AnimationPlayer/Timeline——非 JSON 資料驅動，與本專案「內容皆 JSON＋lint＋require 條件觸發」管線格格不入。

## 1. 目標 / 非目標

### 目標
1. 可重用的**演出播放引擎**：一段 `content/cutscenes/*.json`＝依序播放的 step 陣列，閘住玩家輸入，播完交還控制。
2. **8 種 step 詞彙**涵蓋計劃列的黑幕/標題卡/CG/強制對話/鏡頭震動，外加 `audio`/`wait`/`effects`。
3. **資料驅動觸發**：地圖格 `scene` 加 `cutscene` 鍵即可掛過場（沿用既有 once/require）。
4. **首發真內容**：把已落地的**領航者殘響 `nav_echo_nest`** 從普通 scene 對話升級成真過場（主線 `goblin_menace` 伏筆 A）。取代拋棄式 demo。

### 非目標（本包明確不做，YAGNI）
- **不做拋棄式 demo**（改用真內容驗證）。
- **不碰美術**：CG 用 placeholder 純色（真圖歸美術組）。
- **不產音訊資產**：`audio` step 引語意 id，缺檔靜音（真音效歸音訊組）。
- **不做整段跳過（skip）**：過場不可跳過；單 step 可按鍵提前推進，但無「快轉到結尾」路徑。
- **不做鏡頭平移/縮放（pan/zoom）**：只做 `shake`。
- **不做 boot/章末的持久化觸發**：`maybe_play_once(id)`＋`played_cutscenes`＋save 升版延後到 M-B（真做開場/章末演出時）。A2 只走地圖格觸發 → **save-neutral（不升 v13）**。資料格式本身已支援非格子觸發，只是入口與持久化延後。
- **不做 `cutscene_lint`**：留給 A8 工具鏈那批。

## 2. 資料格式

`content/cutscenes/<id>.json`：

```json
{
  "id": "nav_echo_nest",
  "steps": [
    { "type": "fade",       "to": "black", "duration": 0.6 },
    { "type": "cg",         "image": "nav_echo_relic", "hold": 3.0 },
    { "type": "shake",      "intensity": 6.0, "duration": 0.5 },
    { "type": "audio",      "op": "sfx", "id": "nav_echo_sting" },
    { "type": "dialogue",   "dialogue": "nav_echo_nest" },
    { "type": "fade",       "to": "clear", "duration": 0.6 }
  ]
}
```

### 2.1 Step 詞彙表（8 型，皆輕薄）

| type | 參數（含預設） | 行為 | 阻塞至 |
|---|---|---|---|
| `fade` | `to: "black"｜"clear"`、`duration=0.5` | 螢幕黑幕淡出/淡入 | tween 完成 |
| `title_card` | `title`、`subtitle=""`、`hold=2.5` | 章節標題卡（比例式版面，黑底置中） | `hold` 秒或按鍵 |
| `cg` | `image`、`hold=0`（0＝等按鍵） | 全版事件 CG（重用 `SceneImageCatalog`） | `hold` 秒或按鍵 |
| `dialogue` | `dialogue: <id>` | 跑既有對話圖（重用主場 overlay，effects 走既有接線） | overlay `finished` |
| `shake` | `intensity=5.0`、`duration=0.4` | `_camera` 衰減震動後復位 | `duration` 秒 |
| `audio` | `op: "sfx"｜"bgm"｜"stop"`、`id=""` | `play_sfx(id)` / `play_map_bgm(id)` / `stop_music()` | 即時（不阻塞） |
| `wait` | `duration=1.0` | 純等待（維持當下畫面） | `duration` 秒 |
| `effects` | `effects:[...]` | 重用 `DialogueEffects.apply` 直接改世界狀態、不開對話框 | 即時 |

**推進模型**：`fade/shake/wait` 按時長自動；`cg/title_card` 有 `hold>0` 自動、否則等按鍵；有 `hold>0` 者仍可按鍵提前推進；`dialogue` 走 overlay 自身流程（末端節點任意鍵離開）；`audio/effects` 即時、不阻塞。**無整段 skip。**

### 2.2 驗證規則（`CutsceneData.parse`，鏡射 `DialogueData.parse`）
- 頂層非 dict、缺 `id`、`steps` 非陣列 → 回 `null`。
- 每個 step 須是 dict 且 `type` 為 8 型之一；缺型別/未知型別 → `null`。
- 型別必填缺失（如 `cg` 無 `image`、`dialogue` 無 `dialogue`、`fade` 的 `to` 非 black/clear、`audio` 的 `op` 非三者之一）→ `null`。
- 其餘參數缺失套 §2.1 預設。
- **不在 parse 階段跨檔驗**（dialogue/image/sfx id 是否存在）——缺檔在執行期各自容錯（對話缺→訊息列提示；圖缺→placeholder；音缺→靜音）。跨檔驗證是 A8 `cutscene_lint` 的事。

## 3. 架構與檔案

### 3.1 引擎層（純、可單測）
- **`engine/cutscene/cutscene_data.gd`（`CutsceneData`）**：`static parse(raw) -> CutsceneData`（畸形→null）；欄位 `id: String`、`steps: Array[Dictionary]`。純函式，無 I/O、無節點。

### 3.2 表現層
- **`presentation/cutscene/cutscene_catalog.gd`（`CutsceneCatalog`）**：`static load(id) -> CutsceneData`（載 `content/cutscenes/<id>.json`→`CutsceneData.parse`；缺檔/畸形→null）。逐字鏡射 `DialogueCatalog`。
- **`presentation/cutscene/title_card.gd`（`TitleCard`）**：小 `Control`，比例式版面（anchor 比例、字級固定），顯示 title/subtitle 於黑底置中。獨立好測「版面比例合規」。
- **`presentation/cutscene/cutscene_player.gd`（`CutscenePlayer`，`CanvasLayer`）**：本包核心。
  - 建構時注入依賴：`Camera3D`、`GameState`（給 `effects`/dialogue runner ctx）；AudioManager 為 autoload 直呼。
  - `func play(data: CutsceneData) -> void`（`await`）：閘輸入 → 逐 step `await _play_step(step)` → emit `finished`。
  - 自擁表現表面（高 layer 的 fade `ColorRect` + `TitleCard` + CG `TextureRect` + **自擁 `DialogueOverlay` 實例**），**與 `main._fade`（地圖轉場）／主場 overlay 分離**＝乾淨邊界，代價是多一個 fade `ColorRect` 與一個 overlay 實例（可接受）。
  - **隱患與對策**：`main._on_dialogue_finished` 會 `_player.set_enabled(true)` 並標 once；若 `dialogue` step 重用**主場** overlay，其 `finished` 會誤觸該 handler → 過場中途解鎖玩家/標錯 scene。故 player **自擁** overlay（不接 main 的 finished handler）：`dialogue` step 開自擁 overlay→`await` 其 `finished`；overlay 的 `advanced` 由 player 以 `signal dialogue_advanced(descriptions)` 轉出，main 接到後路由回既有 `_on_dialogue_advanced`（sfx＋訊息列＋hud）。effects 仍直接改 `GameState`（runner ctx 即 GameState）。
  - `shake` step：過場期玩家已 `set_enabled(false)`，安全地在 `duration` 內以衰減 offset 擾動 `_camera` 後復位。
  - `signal finished`。

### 3.3 觸發接線（`main.gd`）
- 擴充 `scene` schema：新增選用 `cutscene: <id>` 鍵。
- `_try_scene(pos)`：若 scene 帶 `cutscene` → 走 `SceneTrigger.should_trigger`（沿用 once/require）→ `_player.set_enabled(false)` → `await _cutscene_player.play(...)` → 復原玩家、依 `once` `mark_scene_triggered`。與既有 `dialogue` 分支平行（一格二選一；若同時給，`cutscene` 優先）。
- 在 `_ready` 建立並掛 `_cutscene_player`，注入 `_dialogue_overlay`／`_camera`；接 `finished`。

## 6. 存檔
**Save-neutral，不升版（維持 v12）**。理由：首發過場走地圖格觸發，沿用既有 `scene_triggered` once 集合，無新持久欄位。`played_cutscenes`（給 boot/章末非格子 once 觸發用）＋`maybe_play_once(id)` 入口延後到 M-B B7 真做開場/章末時再加——屆時依「不需向後相容」直接升版、一併更新測試。

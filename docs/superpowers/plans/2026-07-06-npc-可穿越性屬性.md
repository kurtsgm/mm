# NPC 可穿越性屬性（blocks）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 讓 NPC 預設可穿越（踩上去觸發對話、講完可前進穿過），並以選用屬性 `blocks:true` 支援門衛型實心 NPC。

**Architecture:** questgiver map entity 加選用布林 `blocks`（預設 false）。`world_grid` 只有 `blocks==true` 才把該格移出 walkable；occupant dict 帶 `blocks`。可走 NPC 由玩家「進格」觸發（`main._on_entered_cell` 新增 `_try_questgiver`），擋路 NPC 由既有「撞上」觸發（`_on_player_bumped` 保留）——由格子可走性自動分流。

**Tech Stack:** Godot 4.7（GDScript）、GUT 9.7。

```gdscript
# 踩進可穿越 NPC 格 → 開對話（擋路 NPC 走 _on_player_bumped 的 bump 分支）。
func _try_questgiver(global: Vector2i) -> bool:
	var occ := _world_grid.occupant_at(global)
	if String(occ.get("kind", "")) != "questgiver":
		return false
	var data := DialogueCatalog.load_dialogue(String(occ["dialogue"]))
	if data == null:
		GameState.message_log.push("（對話 %s 遺失）" % occ["dialogue"])
		return false
	_scene_once = false
	_player.set_enabled(false)
	_dialogue_overlay.open(DialogueRunner.new(data, GameState))
	return true
```

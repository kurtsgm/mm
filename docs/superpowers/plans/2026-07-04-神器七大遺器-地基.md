# 神器體系「七大遺器」· 地基 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把「可收集的強大神器·七大遺器」的 **lore ＋ 引擎資料地基** 落進現行 canon 與既有裝備系統（神話品質階、七件 fixed unique、排除隨機池、集齊偵測、lint 守關）。

**Architecture:** 神器＝現行「遺物」用語的頂層，玩法上是 `UniqueCatalog` 之上新開的**神話（MYTHIC）品質階** fixed unique；七件帶 `is_artifact`＋`set_id`，從隨機掉落池排除（只從固定來源進場，屬**後續計畫**）。集齊偵測為純函式模組。全部為純資料/引擎邏輯，皆可 TDD，不依賴尚未存在的地圖/boss/店。

**Tech Stack:** Godot 4.7 / GDScript；測試框架 GUT（`extends GutTest`）。

## Global Constraints

- **引擎/語言**：Godot 4.7、GDScript；測試一律 GUT，放 `tests/` 鏡射原始碼路徑。
- **UniqueCatalog 方法名**：取項用 `UniqueCatalog.entry(id)`，**不可用 `get()`**（4.7 撞 `Object.get`）。
- **神話色**：`#e53935`（緋紅，預設可調）；**售價倍率** `mult = 25.0`（高於傳說 10.0）。
- **set_id**：`"seven_relics"`；**神器數量** = 7。
- **紅線一·階序**：任一神器**不得**自稱/被稱「命脈／全世界的電源／第二核心／養活全世界」；七件之上另有不可見的第八件＝那具核心（聖露希亞）。
- **紅線二·真相**：神器 lore 只放**伏筆碎片**（「這不是魔法、是機器」），不點破完整真相。
- **不需向後相容**：pre-release，改 schema/資料直接改、一併更新呼叫端與 test 資料，不寫遷移。**本計畫不動 save 版本**（神器已以 `ItemInstance` inline dict 序列化，capstone-active 由持有件數推導）。
- **YAGNI/DRY/TDD/頻繁 commit**。

**測試/環境（權威——各 Step 一律照此，勿用其他 GUT 叫法）**
- godot 在 PATH（`/opt/homebrew/bin/godot`, 4.7）。
- **單檔測試**：`godot --headless --path . -s res://addons/gut/gut_cmdln.gd -gdir=res://tests -ginclude_subdirs -gselect=<檔名>.gd -gexit`（`-gselect` 吃**檔名**非路徑）。
- **全套測試**：同上、去掉 `-gselect`。

class_name ArtifactSet
extends Object

# 七大遺器集齊偵測（純函式）。背包實例 + 全隊已裝備，去重 unique_id、只計 is_artifact。
const SET_ID := "seven_relics"
const SET_SIZE := 7

static func owned_ids(inventory, party) -> Dictionary:
	var seen: Dictionary = {}
	if inventory != null:
		for it in inventory.instances():
			_mark(seen, it)
	if party != null:
		for m in party.members:
			var eq: Dictionary = m.equipment.equipped()
			for slot in eq:
				_mark(seen, eq[slot])
	return seen

static func _mark(seen: Dictionary, it) -> void:
	if it != null and it.unique_id != "" and UniqueCatalog.is_artifact(it.unique_id):
		seen[it.unique_id] = true

static func owned_count(inventory, party) -> int:
	return owned_ids(inventory, party).size()

static func is_complete(inventory, party) -> bool:
	return owned_count(inventory, party) >= SET_SIZE

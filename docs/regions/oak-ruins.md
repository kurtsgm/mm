# 枯石谷淺層遺跡・區域內容包

狀態：可玩 blockout，流程驗證用；美術、音訊、手感與遊玩時長待人工驗收。
清單：`content/regions/oak_ruins.json`。章節：ch01 B7。

## 目的與範圍

從多恩的在地差事出發，探索西南野新露出的斷壁，碰到「這石頭不像石頭」的異樣，再把見聞帶回鎮上。兩張 16×16 地圖形成短地城；可自由探索後再接任務。預計 20–30 分鐘是待量測假設，不以走路或重複戰鬥填滿時間。

- `wild_sw` (3,11) → `oak_ruin_vestibule/from_wild`。
- 斷壁入口：南側退路、補給支路、毒蛛遭遇、北側深處入口。
- `oak_ruin_vestibule` (12,2) → `oak_ruin_gallery/from_vestibule`。
- 無縫石廊：西側補給支路、東側夢魘妖遭遇、(12,3) 殘響。
- 沿原路退回西南野，再回橡鎮鐵匠舖。每個入口皆有安全落點，落點與自動 portal 分開。

## Canon 對照

已讀 `world-bible.md` 與 `world-reference.md` §E/F/H，遵循 ch01 B7：

- 只呈現無縫表面、冷、低顫與斷句，不確認飛船、機器、方舟或核心真相。
- 領航者保持無實體、片段化殘響，不揭露身分或獻祭。
- 夢魘妖是本地靈能精怪，未描述成造物主觸手。
- 多恩先保護消息與旅人，沒有提前揭露反抗組織全貌。
- 無新神器、無開盒；未挪用後期 `level01`。

## 資產與品質

沿用 bricks 地城主題、毒蛛／夢魘妖模型、既有道具模型、`dorn_forge` 與 `nav_echo_relic` 圖卡、殘響 SFX。`interior` 與戰鬥音樂仍為既有暫用音訊。入口以舊火盆標記；石廊目前為既有石牆灰模，尚需專屬無縫壁面與遺跡構件。

## 驗收案例與預覽

`normal`：實際 NPC 接任務 → 路線抵達 → 演出 → JSON 存讀檔往返 → once 不重播 → 回報 → 後續對話不重發獎勵。
`early_exploration`：另一個選擇先探索 → 存讀檔 → 接任務追認 → 回報。
`interrupted_scene`：開始後中止 → 未設完成旗標 → 存讀檔 → 重播成功 → once 阻擋。

預覽：`entry`、`echo_before`、`echo_after`、`returned`。後兩者由真實案例的步驟重播建立狀態，不另外手填完成旗標。

人工待驗：完整走查與戰鬥、事件前後實際存讀檔、畫面／聲音與 UI、20–30 分鐘節奏。自動重播不計算戰鬥勝率或遊玩分鐘數。

# 毒澤的解藥・第二個流程驗證案例

清單：`content/regions/oak_antidote.json`。本次沿用既有遊戲資料，新增區域清單、路線與驗收案例。

目的：驗證同一工具能處理採集任務、三個實際寶箱、NPC 回報與獎勵，不依賴枯石谷的旗標或演出寫死邏輯。

路線：橡鎮瑪歌 (8,8) → 野外連通網 → 東南野採藥箱 (5,5)/(9,5)/(7,11) → 瑪歌。

`normal` 從 NPC 接任務開始，採齊後通過正式 JSON 序列化再回報；後續對話不重發 30 金。
`early_collection` 先開三箱、存讀檔、再從 NPC 接任務，確認採集追認；重開箱後仍只持有三株草。

故事與資產對照：`docs/script/quests/oak-antidote.md`，沿用瑪歌對話、毒澤場景圖與採藥箱。

本案例證明既有採集內容可納入共用工具。它量測的是納管成本，尚不能作為第二個全新區域的製作工時。後續新區域應記錄從 brief 到驗收的完整耗時，再校準大規模內容配額。

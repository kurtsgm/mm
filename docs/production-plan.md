### 2.3 尺度警示（M-A 必決）

LOCAL_MAP_SIZE=10 的單圖偏小：50hr 密度下地圖檔數會爆量（>150 張）。M-A 有一個專門決策工作包（A4）評估「升到 16×16（pre-release 免相容成本）」vs「維持 10×10、以區塊 cluster 為預算單位」。**§2.1 的地圖數字以區（cluster）計，不受此決策影響；檔案數受影響。**

## 3. 組織與分工（AI 虛擬工作室編制）

### 3.1 組織圖

```
製作總監（使用者）─ 唯一決策者
 ├── 敘事組        Narrative
 ├── 世界關卡組    World & Level Design
 ├── 任務組        Quest Design
 ├── 系統工程組    Engineering
 ├── 內容數值組    Content Systems & Balance
 ├── 美術組        Art
 ├── 音訊組        Audio
```

每個「組」＝一類可獨立派工的 agent 職能，不是常駐個體。同一個工作包從頭到尾由同職能 agent 收斂；跨職能的依賴由本計劃的流水線順序（§4）管理。

### 3.3 派工協定（每個工作包的生命週期）

1. **Kickoff**：總監與主 agent 對齊範圍 → 依規模走 brainstorming/spec（大包）或直接 writing-plans（小包）。
2. **執行**：subagent-driven development；**sub-agent 一律繼承主對話模型（禁止降級模型）**；內容批次可經總監同意後用多 agent 平行量產＋lint 收斂。
3. **驗收**：code-review → 對應職能的品質工具全綠 → 總監 gate（若該包觸及視覺/聽覺/手感）。
4. **記錄**：更新本檔 §9 進度區＋memory status；未經總監裁示不 push。

### 3.4 只有總監能做的事（計劃的人力瓶頸，明列以便排程）

- 每幕 1 次**通關 playtest**（幕一 ~5h、之後每幕 4–9h、Beta 全程 ~50h——這是整個計劃最大的單人時間投入，Beta 期要預留）。
- 美術**批次審圖**（每批 10–20 張，幕均 2–3 批）與音訊**批次審聽**（每幕 1 批）。
- 每里程碑 kickoff 的選角/命名/取捨拍板（spec 內的「待拍板」條目）。

## 4. 標準生產管線（每幕的九站流水線）

每幕（M-C 起）依同一流水線生產；站與站之間可管線化（前一站部分產出即可開下一站），但**驗收 gate 不可跳**：

| 站 | 職能 | 產出 | gate |
|---|---|---|---|
| 1. 章節劇本 | 敘事 | chNN beat 大綱（ch01 格式：beats/伏筆時間軸/待實作清單） | 總監拍板（canon 檢查附錄） |
| 2. 大陸 blockout | 世界關卡 | 地圖清單/連通圖/動線/遭遇帶/伏筆落點 | 總監拍板（對照 §2 配額） |
| 3. 地圖落地 | 世界關卡 | map JSON 批次 | 尺寸測試＋map_lint |
| 4. 任務對話 | 任務＋敘事 | quest+dialogue 批次 | quest_lint 全綠 |
| 5. 怪物數值掉落 | 內容數值 | monster/item/spell/loot 批次 | loot_lint＋combat sim 勝率帶 |
| 6. 美術換皮 | 美術 | theme/sprite/肖像批次 | 總監批次審圖 |
| 7. 音訊 | 音訊 | 區域曲/戰鬥曲/SFX 接入 | 授權登記＋總監審聽 |
| 8. 平衡收斂 | 內容數值 | 該幕等級帶 sim 報告＋修正 | sim gate（§6.1 門檻） |
| 9. 幕驗收 | QA→總監 | playtest 報告（實測時長/bug 清單） | **幕 DoD（§6.2）全過** |

### 內容單元 Definition of Done（抽驗基準）

- **一張地圖**：尺寸合規、可通行性驗證、遭遇/寶箱/portal 擺放齊、迷你地圖標記正確、有所屬 theme 與 BGM 指定。
- **一條任務**：quest_lint 綠、可完成、不與他任務互鎖、有 XP/獎勵、追蹤器文案齊、（若主線）beat 對照表勾銷。
- **一隻怪**：.tres 數值入 tiered ladder 帶、掉落表掛好、sprite 非 placeholder、戰鬥動畫掛好、（若有異常技）狀態接通。
- **一首曲/一個 SFX**：授權登記入 `ATTRIBUTION-AUDIO.md`、響度不突兀、掛到對應觸發點。
